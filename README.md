# django_resaas

**The backend of RESAAS** - a Django / DRF framework for secure, multi-tenant business applications:
tenants (Entity → Branch), functional permissions grouped in profiles, rotating JWT sessions,
generic CRUD with search and soft delete, a Schema 1.0 contract for the frontend, files and PDF,
notifications, entitlements and pluggable business modules.

Its frontend is [quasar_resaas](https://github.com/metanochava/quasar_resaas); each works on its own.
